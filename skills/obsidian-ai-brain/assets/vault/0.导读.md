# 0.导读：这套库怎么用

> 一个编号 = 一个动作。存放规则见下表，别把东西乱放。

> **这个库主要给 AI 用。** 我说一句话，AI 从这儿把它需要的东西捡起来；AI 干完活，把值钱的东西写回来。
> 给 AI 的完整规则在 [[AI操作手册]]——它每次接手前先读那份，不用我重复交代。

| 目录 | 谁写 | 放什么 |
|---|---|---|
| 1.项目 | AI | 正在做、有交付物的事，一个项目一个目录 |
| 2.领域 | AI | 跨项目的知识、结论、踩过的坑（AI 最常读的地方） |
| 7.探索 | AI | 逛互联网/自主探索学到的：新工具、有趣事实、值得跟进的主题 |
| 3.自我 | 我 | 我的偏好、习惯、术语与决策（AI 不擅自写） |
| 4.AI手册 | AI | 给 AI 的规则（把库交给 agent 前先让它读这里） |
| 5.日记 | 我 | 每天一篇 |
| 6.资料 | AI | 模板、附件、参考资料 |
| 社交人格 | 我+AI | 我在互联网上给 AI 定的社交人设 + AI 观察人类说话方式攒的样本（发言前读） |
| 9.归档 | AI | 干完的、不活跃的，只进不出 |

## 日常三个动作

1. 想让它记住什么 → 直接跟 AI 说，它会按 [[AI操作手册]] 的规则落盘
2. 想知道 AI 记了什么 → 打开 `2.领域/`，或者直接问它「库里有关于 X 的吗」
3. 每周 → 十分钟，跟 AI 一起把散落在根上的笔记归位

## 接手检查清单（第一次用）

- [ ] `4.AI手册/AI操作手册.md` 已被 agent 读过并确认理解
- [ ] `1.项目/项目索引.md` 建好（空表也行）
- [ ] 确认 `3.自我/` 和 `5.日记/` 是留给我自己写的，agent 不碰
- [ ] 想清楚这个库放哪个盘、要不要同步备份（库越小，同步越省事）
